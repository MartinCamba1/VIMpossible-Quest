About

What is VIMpossible Quest?

VIMpossible Quest is a browser-based rogue-lite game designed to help you build Vim muscle memory through repetition and trying to beat as many timed challenges as you can.

Endless timed challenge

Short challenges focused on specific Vim commands.

Speed

Improve how quickly you can perform common commands.

Muscle Memory

Build familiarity through repeated practice.

How It Works

  1. Start each run with the most basic commands.
  2. Complete challenges under a time limit.
  3. At the end of each round, choose one of three Vim commands to unlock.
  4. See how far you can get.
