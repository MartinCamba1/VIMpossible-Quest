What is Vim Trainer?

Vim Trainer is a browser-based rogue-lite game designed to help you build Vim muscle memory through repetition and trying to beat as many timed challenges as you can.

Endless timed challenge

Short challenges focused on specific Vim commands.

Speed

Improve how quickly you can perform common commands.

Muscle Memory

Build familiarity through repeated practice.
